## 排序
- [冒泡排序](bubble.rs)
    每一轮把*最大元素“冒泡”到末尾*
- [桶排序](bucket.rs)
    1. *核心思想*：把数据分到多个桶，每个桶单独排序，最后一次合并所有桶  
    2. *流程：*
       1. 根据最大、最小值，创建若干桶
       2. 将每个元素映射放入对应桶，桶索引计算 ``` ((val-min)/(max-min)) * (bucket_count-1) ```
       3. 每个桶内部排序
       4. 按桶顺序把元素回调原数组
- [鸡尾酒排序](cocktail.rs)  
    *双向扫描：先左->右把大叔冒泡到尾部，再右->左把小数冒泡到头部*，来回摆动。   
    *适合场景*：小的元素集中在数据尾部
- [计数排序](counting.rs)
- [堆排序](heap.rs)  
    核心：基于大顶堆  
    1. 把无序数组构建成大顶堆
    2. 堆顶（下标0）是最大值，把堆顶和堆末尾元素交换
    3. 堆的有效长度减一，对新堆顶做堆调整
    4. 重复直到堆大小为1  
  
    特征：  
    1. 左孩子： 2*i+1
    2. 右孩子： 2*i+2
    3. 父节点： (i-1)/2 
- [插入排序](insert.rs)
    把数组分为已排序区间（左侧）和未排序区间（右侧）。 逐个取未排序区间的第一个元素，向前扫描已排序区间，找到合适位置插入，将更大的元素向后挪，不断扩大左侧有序区间
- [归并排序](merge.rs)
  分治思想：先拆分，再合并。  
  1. 分：把数组不断对半切分，直到每个子数组只有 1 个元素（单个元素天然有序）。
  2. 治（归并）：把两个已经有序的子数组，合并成一个大的有序数组。
